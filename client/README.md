This folder holds client-side material for the spellbook change. It contains **no EverQuest client files**.

* `ui/fix-spellbook-page-labels.ps1` widens the spellbook page-number labels so pages 100+ show all three digits (cosmetic).
* To get a 1440-slot `eqgame.exe`, patch your own with `tools/patcher/` (see the main README and `tools/patcher/README.md`).
